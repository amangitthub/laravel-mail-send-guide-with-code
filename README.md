# Laravel Mail Send Guide with Code

A clean, terminal-style guide for sending HTML emails in Laravel using SMTP, Gmail App Passwords, and a reusable `MailService`.

## 🚀 Live Demo

👉 [View Live Guide](https://amangitthub.github.io/laravel-mail-send-guide-with-code/)

## 📚 What's Inside

- Laravel SMTP mail configuration
- Gmail App Password setup
- `.env` mail configuration
- Reusable `MailService` class
- HTML email template
- Sending mail from Controller
- Customer & Admin email example
- Error handling
- Testing with Laravel Tinker
- Copy-to-clipboard code examples
- Hindi / English language switch

## 🛠️ Technologies

- Laravel 11
- PHP
- SMTP
- Gmail
- HTML
- CSS
- JavaScript
- Bootstrap 5
